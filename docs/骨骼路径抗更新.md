# 骨骼路径的抗更新调查

## 结论先说

**骨骼采样路径没有硬编码骨骼名。** 我上一条说"仍按 `Character_Neck` 这类名字硬编码"是错的，得纠正。

`EnsureBones()` 拿的是整个层级：

```cs
var list = root.GetComponentsInChildren<Transform>(true);
bones = list;
```

**476 个 Transform 全收进来**，靠 `Animator` 的 `SampleAnimation` 取姿势，不点名。游戏换骨架、改骨骼命名、加骨骼，全部跟着走。

## 真正的名字依赖只有一处

`upperAllowed` —— **头颈分账池**。它决定：

```cs
bool isHead = upperAllowed[i];
if (isHead) { headDeg / headSpd }   // 头部预算
else         { bodyDeg / bodySpd }  // 身体预算
```

名字判据是子串（`Head` / `Neck`），已经不是精确名。

**这里踩了个坑，记下来**：我以为它是"上半身"池，顺手加宽到 `Head|Neck|Chest|Spine|Shoulder|Clavicle|Arm|Hand|Finger`，结果 `clamp` 从 **1° 涨到 1673°**。

原因：加宽后 `headDeg` 把手臂手指的幅度也算进去了（`amp=head 85.9` 而 `body 32.5`），分账彻底反过来。手指动 85° 被记成"头动了 85°"，头部预算被撑爆，每帧狂削。

**回退后**：

| | head | body | clamp |
| --- | --- | --- | --- |
| 加宽（错） | 85.9 | 32.5 | **1673°** |
| 回退（对） | 24.0 | 85.9 | **2°** |

敲键盘本来就是手臂动、头动得少，`head 24 / body 86` 才是对的。

**教训：这个名字叫 `upperAllowed`，但语义是「头颈」，不是「上半身」。** 名字起错了会骗人。

## 加了什么

**名字全失效时退到世界高度**：

```cs
if (namedUpper == 0 && list.Length > 0)
{
    float cut = lo + (hi - lo) * 0.55f;   // 躯干中线
    // 世界 Y 高于中线的算头颈
}
```

只在 `namedUpper == 0` 时启用——正常情况名字比高度准得多（她躺下时头会低于骨盆）。

日志加了来源标记：

```
head bone: idx=183 name=Head upper=15/476 via=name
```

`via=height>0.87(31)` 就说明走了兜底路径。

## 还没验的

**高度兜底这条路径没实测过**——名字在所有情况下都命中了（`upper=15/476 via=name`），没触发。

要验它得临时把名字判据关掉跑一次，属于改代码测代码。代码逻辑简单（算 Y 的 55% 分位），但**"没跑过"就是"没跑过"**，别当成已验证。

## `headIdx` 的初始值是误导的，但无害

```
head bone: idx=183 name=Head
```

选中的是名字最短的含 "Head" 的 Transform，也就是那根**静态的** `Head`（`Character` 下同时存在 `Head` 和真正被驱动的 `Character_Head`）。

但 `headIdx` 在采样时会被重挑：

```cs
// 名字带 Head 且真的在动的骨里取最大者，否则退到 upper 里最大者
if (pickHead >= 0 && pickHeadDev >= 1f) headIdx = pickHead;
else if (pickAny >= 0) headIdx = pickAny;
```

用的是**实际幅度**，不是名字。所以日志那行只是初始化时的一个快照，`headIdx` 声明处 `= -1` 也说明它靠后赋值。

## 稳定性回归

回退后的实测：

```
peakHead=22dps@t3.81s/dt16.7ms dev=0.2deg amp=head24.0/body85.9deg clamp=2°
```

`dev=0.2deg` 是交接差（放手瞬间我们的输出与游戏姿势的角差），**0.2° 基本等于无缝**。加宽那次是 `dev=6.5deg`。

## 真正的抗更新缺口（按性价比排）

| 缺口 | 断了会怎样 | 兜底 |
| --- | --- | --- |
| 原生动作枚举名 | 该动作回落采样 | 有 |
| 口型 blendshape 名 | 嘴不动，**有 warning + 列出名字** | 有（上一条改的） |
| 头颈分账 | 限幅算错，动作被削 | 名字全失效时退高度 |
| 脸网格名 | 找不到脸 | 已改成按母音匹配 |
| 骨骼名 | **不存在这个问题** | — |
