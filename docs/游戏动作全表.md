# 游戏原生动作全表（`Bulbul.HeroineService+AnimationType`）

来源：运行时反射 `enum HeroineService` 全量导出（`data/anim-types.txt`），共 261 个值。
这些是**游戏自己会做的动作**，通过 `HeroineService.ChangeAnimation(AnimationType)` 触发。

> 命名规则：`<基底>_<子动作>`。同一个子动作在不同基底下各实现一遍，姿势基准不同——
> 比如 `DrinkTea` 在 BreakBase004 / WorkBase001 / WorkBase002 / WorkBase003 里都有。
> 完整矩阵见 [游戏动作组合模型.md](./游戏动作组合模型.md)。
