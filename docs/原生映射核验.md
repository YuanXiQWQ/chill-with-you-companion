# 原生映射核验

## 方法

`game/assets.seed.json` 里 389 条 clip **每条都带游戏自己写的中文语义标注**（`semantic` 字段）。这是比看画面更硬的依据——它不需要判断"这个动作看起来像不像喝水"，游戏自己说了它是什么。

```powershell
$j = Get-Content 'game\assets.seed.json' -Raw -Encoding UTF8 | ConvertFrom-Json
$j.animations | Where-Object { $_.id -eq 'anim_wild_wet' } |
  ForEach-Object { $_.semantic -join ',' }
# → 站立动作,被淋湿
```

`AnimationType` 枚举名与 clip 名的对应相当稳定：

```
Wild001_Motion1_StretchFllBody  →  anim_wild_stretchfullbody
Wild001_Motion3_Tea             →  anim_wild_tea_base
Wild001_Motion5_Wet             →  anim_wild_wet
Base001_Motion12_Start_Nod      →  anim_story_base001_sub_nod
```

## drink 的修正

按名字猜 `Wet` ≈ 喝水 / 润嘴唇。**实际是「被淋湿」**，3000ms 的站立动作。

游戏里没有独立的"喝一口水"原生动作：

```
anim_wild_tea_base      站立动作,喝茶,基本      7333ms   ← tea 已占用
anim_break_tea_sub_drink  休息,喝茶,子动作      1833ms   ← 坐着喝，就是采样用的
```

已改为 `native: null`，走采样路径 `anim_break_tea_sub_drink`。

## 更根本的问题：坐姿还是站姿

`Wild001` 全族 25 个动作的语义都是**「站立动作」**（91 条 clip）。而她默认坐在椅子上（`RoomPlace.Desk`）。

各族语义分布：

| 语义 | 条数 | 说明 |
| --- | --- | --- |
| 剧情动作 | 150 | 坐着 |
| 站立动作 | 91 | 站着 |
| 休息 | 71 | 坐着 |
| 工作 | 42 | 坐着 |
| 表情 | 19 | 只动脸 |

**座位上的候选**：

```
anim_break_yawn_1_*                      休息,打哈欠           ← 已用（正确）
anim_story_base001_sub_dropshoulders_*   剧情动作,垂肩         ← 揉肩的坐姿版
anim_break_tea_base_*                    休息,喝茶,基本        ← 喝茶的坐姿版
```

**只有站立版、没有坐姿版的**：伸懒腰、深呼吸、疲惫。

## 站姿疑虑：已排除

「站立动作」是**动作库分类**，不是「播放时会站起来」。用 `hips` 命令读骨骼世界坐标实测：

```
基线 BreakBase001（坐着）            worldY = 0.571
Wild001_Motion1_StretchFllBody       worldY = 0.580 / 0.556 / 0.587
回到 BreakBase001                    worldY = 0.578 → 0.571
```

**波动 ±0.016 m（1.6 厘米），是坐姿下的躯干起伏。** 真站起来会是 +0.45 m 量级（0.571 → 1.0 左右）。

结论：`Wild001` 那 5 条（stretch / shoulder / tea / tired / breathe）在座位上可以安全使用，不需要换成 `break` 族。

### 探针命令

`game/src/ReflectConsole.cs` 新增 `hips`：

```
$ echo 'hips' > BepInEx/chill-cmd.txt
name=Character_Hips worldY=0.571 localY=0.571 anim=BreakBase001
```

打印 Hips 的世界/局部高度，顺带报当前 `_currentAnimationType`。判据很简单：**只要有几十厘米的跃升就是离座了**。

> 无参 verb 必须在 `parts.Length < 2` 的 guard **之前**分发，否则会得到 `ERROR need a type pattern`。`anim` 和 `hips` 都栽过这一下。

## 复现

```powershell
$j = Get-Content 'game\assets.seed.json' -Raw -Encoding UTF8 | ConvertFrom-Json
$j.animations | Where-Object { $_.semantic -notcontains '站立动作' } |
  Where-Object { $_.id -match 'stretch|yawn|shoulder|breath' } |
  ForEach-Object { "$($_.id)  $($_.semantic -join ',')" }
```
