## 二、表演链路现在长什么样

```
一句话
  ├─ 分类：477 clips → gesture 91 / prop 45 / posture 31 / locomotion 33 / idle 17
  ├─ 闸门：内容指向某类（喝/写/困/走）而模型选错类 → 换掉（gate.log 可查）
  ├─ 形态：手势=单段；道具/姿态/位移=整族（start→loop 一拍→end）
  ├─ 时序：与语音**完全无关**；同族 20s 内只接 loop（perfMemo）
  ├─ 起手：从「她此刻的姿势」进入（SwitchBlendMs 340ms）
  ├─ 途中：BodyDegBudget 26° / HeadDegBudget 15° / 速度预算 320·160 dps
  ├─ 回归：逐帧问游戏"你现在会把她摆成什么样"，按距离伸缩归还（0.3–0.9s）
  └─ 排队：后面还有动作 → 归还压到 50ms，下一套以她的最后姿势起步（chain）
```

实测指标（本机，2026-11-15）：

| 指标 | 数值 | 含义 |
| --- | --- | --- |
| 交接差 `handoff dev` | 0.00 – 0.71° | 放手瞬间与游戏姿势的最大角差，肉眼不可见 |
| 归还时长 | 50ms（有队列）/ 314–900ms（无队列，随距离） | 不是固定值 |
| 段内幅度 `amp` vs 计划 `plan` | 对齐（喝了茶 13.0/77.5 vs 10.5/77.0；离座 34.8/179.7 vs 34.8/140.6） | `moved=head:1/body:1`，无 MISS |
| 分类准确率 | 18/18（类别 + 内容双百） | `eval-motion 3` |
| 端到端 | 13/13 | `test-live` |
| 离线回归 | 21 个测试文件 / 36 条不变量 | `run-tests` / `verify-motion` |

## 三、今天修掉的四件事（都有数字）

1. **起点是"插入"不是"接管"**：归还改成逐帧读游戏姿势（旧快照方案 `handoff dev=22.58°`，现在 0.00°）。
2. **表演与语音解绑**：四处耦合拆掉（`loop` 重复次数、`end` 挂语音结束、起手按语音归一化、`clipLen` 被 `durationMs` 撑到 1.35 倍）。同一条动作在 1.5s / 12s 语音下时间线完全一致。
3. **编排按内容定形态**：手势不再摊成整族（点头 5160→2167ms）；同族 20s 内延续（喝茶 4327→1327ms）。
4. **排队衔接**：`waited=3.1s`（等上一套演完）+ `rel=50ms`（有队列时压缩归还）+ `chain: 下一套接上`。

## 五、差距与债务（按严重度）

> 2026-11-15 复核后，原表里三条其实不成立 —— 留着"假债"比漏掉真债更糟，先说清：

| 原判断 | 复核结论 |
| --- | --- |
| 双编排并存，改 A 被 B 覆盖 | **真债，已修**。`planSequence` 现在只排序/串行化（`cues` 里一条动作就是一条，不再自己摊成 start→loop→end）；`chainStartToLoop` 是唯一展开点；出口统一去重。`verify-motion` 新增「planSequence 只排不展开（展开唯一在 chain）」把它钉住 |
| `plan` 对 `_end` 段量错幅度（yawn_1_end amp 118.6° vs plan 0.2°） | **伪问题**。`plan` 只量 clip 自身幅度，`amp` 量的是"从第一帧输出到峰值"，含进入过渡的混合量，两者本来就不同量纲。回退实验后对照：伸懒腰 `plan peakBody=168°` vs `amp body=167.8°`，差 0.2°。校验以 `plan` 为准，`amp` 只看 `moved` |
| `MaxClipSec=8` 裁掉 8567ms 的位移段 | **伪问题**。8s 只是兜底值；每类有自己的 `MotionProfile.MaxSec`，locomotion 是 **20s**，那段完整播完（实测 `frames=353 wall=8.57s`） |

## 六、风险（游戏官方更新时会发生什么）

| 风险 | 现在的抵抗力 |
| --- | --- |
| clip 改名 / 增删 | 运行时从游戏 dump 清单（`/game` → `data/assets.json`），离线 `assets.seed.json` 只作兜底；未知名会 `anim id unknown` 记日志并跳过，不会崩 |
| 家族结构变化（少了 `_end`） | `chainStartToLoop` 按 `has()` 逐段判断，缺段就降级（单段/只有 start） |
| Animator 层/参数改名 | 反射 + `clipOwners` 反查；`CrossFadeInFixedTime` 只吃 state 名这点已用负结果绕开 |
| 场景新增（新玩法） | `NON_PERFORMANCE_SCENES` 白名单需要人工补；新场景动作会被当 `unknown`，不会误演 |
| 游戏改骨骼层级 | `EnsureBones` 按名字找；找不到就整段不演（安全降级） |

**唯一无法自动抵抗的**：官方把 idle 状态机改成"不再自动推进"。那时回归的"归还到 live idle"会失去意义 —— 但这属于游戏根本性改动，届时再评估。
